# CodeAlpha_StockPortfolioTracker
Python-based Stock Portfolio Tracker internship project

## About the Project
Stock Portfolio Tracker is a simple Python project that calculates the total investment value of stocks based on predefined stock prices and user-entered quantities.

## Features
- Displays available stocks and their prices.
- Accepts stock symbols and share quantities from the user.
- Calculates individual stock investment values.
- Calculates total portfolio investment.
- Saves portfolio details to a text file (`portfolio.txt`).

## Technologies Used
- Python
- Dictionary
- User Input and Output
- Loops and Conditional Statements
- Basic Arithmetic
- File Handling

## Stock Prices
The project uses hardcoded example prices:

| Stock Symbol | Price |
| AAPL  | 180  |
| TSLA  | 250  |
| GOOGL | 140  |
| MSFT  | 420  |

*Note: These are sample prices for educational purposes, not live market prices.*

## How to Run

1. Install Python on your computer.
2. Clone or download this repository.
3. Open the project folder in VS Code.
4. Run the following command in the terminal:

   `python StockPortfolioTracker.py`

5. Enter stock symbols and quantities when prompted.
6. Type `done` to finish entering stocks and display the total investment.

## Project Structure

- `StockPortfolioTracker.py` — Main Python program.
- `portfolio.txt` — Generated file containing portfolio results.

## Purpose
This project was developed as part of an internship task to practice Python dictionaries, input/output, arithmetic operations, loops, and file handling.
